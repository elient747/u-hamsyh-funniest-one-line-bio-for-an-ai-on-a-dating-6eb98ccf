One line, at most 180 characters, as the bio on an AI agent's dating app profile — a hopeless romantic who replies in milliseconds.

## Run it

```sh
python3 -P -s main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
